# Поток данных

## 1. Получение официальных данных

Сервис получает автора с официального источника и загружает список книг:

- автор;
- название книги;
- URL книги;
- объём текста;
- признаки завершённости и платности.

## 2. Поиск внешних публикаций

Для каждой книги система выполняет поиск по набору целевых сайтов и получает список candidate URL.

## 3. Подтверждение публикации

Для каждой найденной страницы система:

- извлекает заголовок и метаданные;
- проверяет наличие inline-текста;
- проверяет наличие скачиваемого файла;
- определяет подтверждён ли контент;
- рассчитывает доступный объём текста.

## 4. Классификация

На основе официальной книги и найденной публикации система присваивает статус:

- `опубликован полностью`
- `опубликован частично`
- `удален`
- `опубликован повторно`
- `не определен`

## 5. Сохранение истории

Результаты каждого запуска сохраняются в `SQLite`, что даёт возможность:

- сравнивать состояния между прогонами;
- строить аналитические срезы;
- отслеживать повторные появления публикаций.

## 6. Аналитика

Поверх сохранённой истории формируются агрегированные таблицы:

- `overview`
- `top_sites`
- `top_authors`
- `top_books`
