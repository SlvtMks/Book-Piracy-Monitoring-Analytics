# Обзор проекта

## Идея

Проект решает задачу мониторинга внешних публикаций книг для авторов и правообладателей. Система ищет совпадения на целевых сайтах, подтверждает тип публикации, сравнивает найденные данные с официальным источником и сохраняет историю проверок.

## Основные сущности

- `author` - автор официальной книги
- `book` - книга из официального источника
- `site` - внешний сайт, на котором проверяется наличие публикации
- `finding` - найденное совпадение по книге на внешнем сайте
- `run` - отдельный запуск мониторинга
- `history row` - запись для повторного анализа и аналитики

## Что уже реализовано

- сбор списка книг с официальных источников;
- поиск совпадений по внешним сайтам;
- подтверждение публикации по странице, тексту и файлу;
- классификация статусов;
- сохранение истории в `SQLite`;
- экспорт истории и аналитики в `CSV/XLSX`.

## Что важно с инженерной точки зрения

- отдельные адаптеры по источникам;
- общий orchestration-слой;
- нормализация строк и статусов;
- воспроизводимый CLI;
- тесты на ключевые сценарии.
