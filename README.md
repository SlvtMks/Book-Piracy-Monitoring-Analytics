# Book Piracy Monitoring & Analytics

MVP-сервис для мониторинга внешних публикаций книг, хранения истории проверок и построения аналитических отчётов по найденным размещениям.

Проект можно использовать в двух ролях:

1. Как monitoring-систему для авторов и правообладателей.
2. Как data analytics кейс: сбор, нормализация, классификация и анализ данных из нескольких источников.

## Что делает проект

Основной pipeline:

1. Получает автора и список его книг с официального источника.
2. Ищет совпадения по `автор + название` на целевых сайтах.
3. Подтверждает тип найденной публикации: карточка, фрагмент, онлайн-чтение, скачиваемый файл.
4. Сравнивает найденные данные с официальной книгой.
5. Присваивает статус публикации: `опубликован полностью`, `опубликован частично`, `удален`, `опубликован повторно`, `не определен`.
6. Сохраняет историю запусков в `SQLite`.
7. Формирует экспортные и аналитические отчёты в `CSV/XLSX`.

## Основные возможности

- адаптеры официальных источников;
- поиск по нескольким внешним сайтам;
- парсинг карточек книг, inline-чтения и скачиваемых файлов;
- нормализация сущностей `автор`, `книга`, `сайт`, `статус`;
- сохранение истории запусков и изменений;
- экспорт истории проверок;
- аналитическая сводка по авторам, книгам и сайтам;
- локальный CLI и GUI.

## Аналитический слой

Поверх накопленной истории проект умеет строить:

- число найденных публикаций по авторам;
- число уникальных книг с утечками;
- самые проблемные сайты;
- распределение полных и частичных публикаций;
- случаи удаления и повторного появления;
- агрегированные таблицы для дальнейшей визуализации в Python, BI или spreadsheet-инструментах.

Пример запуска:

```bash
python main.py analytics-report --author-name "Арина Арская"
```

Команда формирует набор отчётов в `reports/analytics`:

- `overview`
- `top_sites`
- `top_authors`
- `top_books`

## Быстрый старт

Установка:

```bash
python -m pip install -e .
```

Запуск GUI:

```bash
python main.py gui
```

Проверка автора:

```bash
python main.py run --author-url "https://litnet.com/ru/arina-arskaya-u9986314"
```

Ограниченный прогон:

```bash
python main.py run --author-url "https://litnet.com/ru/arina-arskaya-u9986314" --max-books 3 --max-sites 5
```

Выгрузка истории:

```bash
python main.py export-history --author-name "Арина Арская"
```

Аналитическая сводка:

```bash
python main.py analytics-report --author-name "Арина Арская"
```

## Структура

- `config/target_sites.json` - список целевых сайтов
- `pirate_monitor/` - доменные модели, HTTP, нормализация, парсинг
- `pirate_monitor/` - основная логика проекта: orchestration, storage, поиск, парсинг, экспорт, аналитика и source adapters
- `tests/` - тесты ключевых сценариев
- `reports/` - generated-отчёты
- `scripts/import_target_sites.py` - импорт списка сайтов из Excel

## Что даёт проект для бизнеса

- показывает, где именно находится контент автора;
- позволяет оценить масштаб нарушения, а не только факт наличия;
- хранит историю удаления и повторного появления;
- помогает приоритизировать сайты по риску;
- создаёт основу для последующего takedown workflow и управленческой отчётности.
